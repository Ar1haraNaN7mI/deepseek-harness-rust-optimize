# DSH 设置中心

网页左下角「设置」或 `Ctrl / ⌘ + ,` 打开。这里管理 DSH 的浏览器偏好、本机模型连接、执行权限、扩展与任务；只显示已经接入的功能。分类可以搜索。

## 真实运行时功能

| 分类 | DSH 中的实际行为 |
| --- | --- |
| 通用 | 保存默认模型与思考模式，作用于后续模型请求；展示当前服务与工作区 |
| 模型服务 | 配置后端、服务地址、模型和凭据；保存或移除本机密钥，可显式允许向本机网关发送密钥，向所配置的服务发起真实推理测试 |
| 个人资料 | 显示名、操作员编号，保存至本机，与 CLI 启动画面共用 |
| 个性化 | 自定义指令、回复风格、温暖程度、热情程度、标题和列表、表情；实际写入模型提示 |
| 记忆 | 引用 / 生成开关，查看、删除记录、清空；删除时重建派生权重 |
| 归档会话 | 查看、归档、恢复、删除会话；操作后刷新工作台 |
| 存储、用量 | 实际会话和消息数量、工具调用数量、会话 / 记忆 / 事件文件字节数；不伪造 token 或费用 |
| 数据控制 | 批量归档、删除对话记录；JSON / Markdown 导出 |
| 执行权限 | 修改工具审批策略、沙箱范围与安全研究提示模式，由 DSH 执行层处理 |
| 插件与 Skills | 本机插件安装、启停和受管安装卸载；查看与启停 Skills；修改影响运行时注册表和工具可见性 |
| 本机工作区 | 读取当前目录与 Git 状态，导入 DSH SEARCH / REPLACE 补丁、检查是否可应用，再明确应用到工作区 |
| DSH 任务 | 提交真实任务，查看执行状态和结果，暂停、继续或取消本机任务 |
| 代码审查 | 读取当前工作区真实 Git 差异，预览审查输入，再交给已配置的模型执行审查 |

运行时表单保存成功后才显示完成。模型配置与扩展发生改变后，设置和工作台重新读取服务状态；连接测试失败会显示实际错误。执行中的任务不会因为页面切换而消失。

## 浏览器与启动体验

| 分类 | 实际行为 |
| --- | --- |
| 外观 | 系统 / 浅色 / 深色主题、强调色、文字大小、界面密度、减少动画、思考内容与工具详情显示 |
| 通知 | 任务完成和工具审批提醒、可选提示音；浏览器授权后可在页面后台时显示桌面通知 |
| 语音 | 逐段试听已安装的英文启动录音，包括工作区、操作员身份、已挂载能力、完成及异常状态；不调用系统 TTS |
| 宠物 | 显示或隐藏本机小猫，和任务工作状态联动 |
| 键盘 | Enter 或 Ctrl / ⌘ + Enter 发送；中文输入法组字期间不会误发送 |
| 启动动画 | 每次 / 仅下次网页播放、CLI 下次播放、立即重播；网页不会消耗 CLI 的一次性标记 |

## 保存与数据范围

- 界面偏好仅保存在当前浏览器；不会改变 CLI 的配色。启动一次性标记使用独立存储，重置界面不会消费它。
- 模型、个性化、记忆策略保存至 `outer_home/settings.toml`，网页和后续 CLI 使用同一配置。运行中的其他进程在重启后读取新配置。
- 密钥不通过读取设置或数据导出返回给浏览器。模型连接测试会向用户配置的地址发送真实请求。
- 自定义指令最多 8000 个 Unicode 字符。小模型仍遵守系统提示总预算，超出时保留前段；重要要求应放在开头。
- 全局 `learn.enabled = false` 时，网页记忆偏好不能绕过这个配置禁用。已生成的消息不会因修改记忆开关而自动改写。
- 删除对话只删除对话快照。用于运行恢复和审计的事件日志独立保留，不宣称完全擦除全部工作数据。进行中或待执行的会话会拒绝归档 / 删除。
- 导出包含对话内容（可含工具输出和用户自己写入的敏感文本），不导出模型密钥、MCP 环境变量或连接头。导出在浏览器下载至本机。
- 插件操作只针对本机 DSH 扩展。卸载只能删除由安装功能管理的副本，不删除用户提供的源目录。
- 补丁检查和代码审查本身不等于应用修改；应用补丁需在页面明确执行，由 DSH 补丁引擎实际验证与写入文件。
- 写入失败会返回错误，不显示已保存。破坏性操作在界面中单独确认。

## 功能边界

DSH 是本机 Harness。设置中没有第三方账户、订阅账单、托管云电脑、云端代码任务、云审查、密码保险库或家庭账户的占位入口。模型请求使用你配置的实际服务；页面不伪造连接状态、Token 用量或消费金额。

界面语言目前为简体中文。启动录音为固定英文片段，用户名使用通用称呼 `OPERATOR`；不提供实时语音对话、听写或声音训练界面。MCP 的运行支持以实际注册的工具为准，不把配置记录当成已连接的服务。

显式保存的 Temperature、推理开关和输出 token 上限优先于小模型优化默认值。代码审查基于实际 Git 差异，未跟踪文件需先暂存；审查沿用当前 DSH 工具权限，通过任务指令要求不修改文件，不是独立只读沙箱。
