# Harness 设置中心

网页左下角「设置」或 `Ctrl / ⌘ + ,` 打开。结构参考 2026-10-07 的 ChatGPT 网页头像菜单设置，并保留 DSH 原生启动序列。分类可以搜索；浏览器偏好立即生效，运行时表单保存后作用于后续模型调用。

| 分类 | DSH 中的实际行为 |
| --- | --- |
| 通用 | 模型名称、推理模式；展示当前运行时状态 |
| 外观 | 系统 / 浅色 / 深色、强调色、消息字号、密度、减少动画 |
| 通知 | 完成和授权提醒、可选提示音；浏览器授权后可在后台显示桌面通知 |
| 个人资料 | 显示名、操作员编号，保存至本机，与 CLI 启动画面共用 |
| 个性化 | 自定义指令、回复风格、温暖程度、热情程度、标题和列表、表情；实际写入模型提示 |
| 记忆 | 引用 / 生成开关，查看、删除记录、清空；删除时重建派生权重 |
| 归档会话 | 查看、归档、恢复、删除会话；操作后刷新工作台 |
| 存储、用量 | 实际会话和消息数量、工具调用数量、会话 / 记忆 / 事件文件字节数；不伪造 token 或费用 |
| 数据控制 | 批量归档、删除对话记录；JSON / Markdown 导出 |
| 安全 | 本机权限、审批策略与沙箱设置；显示真实账户 / 服务性质 |
| 插件 | 已挂载插件与技能；MCP 明确显示「已配置」，不假称已连接 |
| 语音 | 播放预生成的英文启动旁白；不调用系统 TTS |
| 宠物 | 可选本机猫咪，与工作状态联动 |
| 键盘 | Enter 或 Ctrl / ⌘ + Enter 发送；IME 输入期间不会误发送 |
| 启动 | 网页长期 / 下次播放、CLI 下次播放、重播；保持既有一次性语义 |

## 与 OpenAI 账户服务的边界

这是本地 DSH 应用，不是登录 ChatGPT 的替代客户端。ChatGPT 的订阅与账单、邮件 / 手机号、密码与 MFA、通行密钥、登录设备、家长控制、可信联系人、云电脑、云代码审查、密码库和共享链接，需要相应的账户与云服务。对应分类解释这一限制并提供官方管理入口，不将本地开关伪装成 OpenAI 账户操作。

界面语言目前为简体中文；实时语音对话、听写、图像参考、自动个人写作风格提取、插件安装 / 停用、云宠物制作等未接入的能力不会显示为可用。MCP 当前只有配置注册表，实际连接能力取决于后续运行时实现。

## 保存与数据范围

- 界面偏好仅保存在当前浏览器；不会改变 CLI 的配色。启动一次性标记使用独立存储，重置界面不会消费它。
- 模型、个性化、记忆策略保存至 `outer_home/settings.toml`，网页和后续 CLI 使用同一配置。运行中的其他进程在重启后读取新配置。
- 自定义指令最多 8000 个 Unicode 字符。小模型仍遵守系统提示总预算，超出时保留前段；重要要求应放在开头。
- 全局 `learn.enabled = false` 时，网页记忆偏好不能绕过这个配置禁用。已生成的消息不会因修改记忆开关而自动改写。
- 删除对话只删除对话快照。用于运行恢复和审计的事件日志独立保留，不宣称完全擦除全部工作数据。进行中或待执行的会话会拒绝归档 / 删除。
- 导出包含对话内容（可含工具输出和用户自己写入的敏感文本），不导出模型密钥、MCP 环境变量或连接头。导出在浏览器下载至本机。
- 写入失败会返回错误，不显示已保存。破坏性操作在界面中单独确认。

官方参考：[个性化](https://learn.chatgpt.com/docs/personalize)、[设置说明](https://learn.chatgpt.com/docs/reference/settings)。不同账户或版本的 ChatGPT 分类可能不同。
